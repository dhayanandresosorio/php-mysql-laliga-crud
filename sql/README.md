# SQL scripts

Scripts SQL para preparar la base de datos del proyecto PHP MySQL LaLiga CRUD.

Orden recomendado:

1. `01_create_database.sql`
2. `02_create_tables.sql`
3. `03_create_app_user.sql`
4. `04_sample_data.sql`

> [!IMPORTANT]
> Sustituir `CHANGE_ME_DB_PASSWORD` por una contraseña local antes de ejecutar el script de creación de usuario.
